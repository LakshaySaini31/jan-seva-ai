# Jan Seva AI (जन सेवा AI) — National Smart Scheme & DBT Discovery Portal

> **An Upgraded Digital Public Infrastructure (DPI) Prototype of India's [myScheme.gov.in](https://www.myscheme.gov.in) Portal**  
> Built with GIGW 3.0 Compliance, Rule-by-Rule Eligibility Transparency, DigiLocker Document Readiness Vault, and Real-Time Cloud + REST Backend.

---

## 🚀 What Problems We Solved vs. Legacy myScheme Portal

| Legacy Portal Pain Point | Jan Seva AI Solution |
| :--- | :--- |
| **1. Tedious 7-Page Static Wizard** | **Bhashini Conversational NLP Search + 1-Screen Live Sliders**: Type in plain English/Hindi or adjust sliders with 0ms reload. |
| **2. Opaque "Black-Box" Rejections** | **Rule-by-Rule Eligibility Diagnostic Matrix**: Shows exact pass/fail badges (`✔ Age 18 fits 16-25`, `✖ Income exceeds cap`). |
| **3. Dense Official Gazette Legalese** | **1-Click Explanation Toggle**: Switch between **AI Simplified Summary** and **Verbatim Official Gazette Clause**. |
| **4. 68% Rejection from Missing Docs** | **DigiLocker Document Readiness Vault**: Pre-verifies 8 core certificates (Aadhaar e-KYC, NPCI Bank Seeding, Income Cert, Marksheet) before applying. |
| **5. Mutually Exclusive Scholarship Traps** | **Side-by-Side Exclusivity Comparator**: Warns students before they lock themselves out of higher-paying NSP scholarships (e.g., AICTE Pragati ₹50k vs PM-USP ₹12k). |
